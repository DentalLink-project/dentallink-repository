```
사용자 → ChatbotController → ChatbotService → Claude API → 응답
   ↓                              ↓
  JWT 인증                    세션 관리

```

## 🔄 단계별 상세 워크플로우

### Step 1: 사용자가 메시지 전송

**HTTP 요청:**
```http
POST /api/chatbot/messages
```

**설명:**

- `sessionId: 1` → 기존 대화 이어서 하기
- JWT 토큰 필수 (인증된 사용자만 사용 가능)

### Step 3: ChatbotService - 세션 확인 또는 생성

**코드:**
```java
@Transactional
public ChatResponse processMessage(ChatRequest request, Long userId) {
    
    // 1️⃣ 세션 확인 또는 생성
    ChatSession session;
    if (request.sessionId() == null) {
        // 새 세션 생성
        User user = userRepository.findById(userId)
                .orElseThrow(() -> new GlobalException(
                    ChatbotErrorCode.USER_NOT_FOUND));
        
        session = ChatSession.create(user, SessionMode.AI);
        chatSessionRepository.save(session);
        
        log.info("새 세션 생성: sessionId={}, userId={}", 
                session.getId(), userId);
    } else {
        // 기존 세션 찾기
        session = chatSessionRepository.findById(request.sessionId())
                .orElseThrow(() -> new GlobalException(
                    ChatbotErrorCode.SESSION_NOT_FOUND));
        
        // 세션 소유자 확인
        if (!session.isOwnedBy(userId)) {
            throw new GlobalException(ChatbotErrorCode.UNAUTHORIZED);
        }
    }
    
    // 2️⃣ 사용자 메시지 저장
    ChatMessage userMessage = ChatMessage.create(
            session,
            MessageType.USER,
            request.content()
    );
    chatMessageRepository.save(userMessage);
    
    log.info("사용자 메시지 저장: messageId={}, content={}", 
            userMessage.getId(), request.content());
    
    // 3️⃣ AI 응답 생성
    if (session.getMode() == SessionMode.AI) {
        return processAIMessage(session, request.content());
    } else {
        return processConsultantMessage(session, request.content());
    }
}
```

**여기서 일어나는 일:**
1. **세션 ID가 없으면** → 새 `ChatSession` 생성 (mode: AI, status: ACTIVE)
2. **세션 ID가 있으면** → 기존 세션 조회 & 권한 확인
3. 사용자 메시지를 `ChatMessage`로 저장 (type: USER)
4. 세션 모드에 따라 AI 또는 상담원 처리 분기

### Step 4: AI 응답 생성

**코드:**
```java
private ChatResponse processAIMessage(ChatSession session, String userMessage) {
    
    // 1️⃣ 대화 히스토리 로드
    List<ChatMessage> history = chatMessageRepository
            .findBySessionIdOrderBySentAtAsc(session.getId());
    
    log.info("대화 히스토리 로드: sessionId={}, count={}", 
            session.getId(), history.size());
    
    // 2️⃣ Claude API 호출 준비 - 히스토리를 Claude 형식으로 변환
    List<Message> messages = history.stream()
            .map(msg -> Message.builder()
                    .role(msg.getType() == MessageType.USER ? "user" : "assistant")
                    .content(msg.getContent())
                    .build())
            .collect(Collectors.toList());
    
    // 3️⃣ Claude API 호출
    MessageRequest claudeRequest = MessageRequest.builder()
            .model("claude-sonnet-4-20250514")
            .maxTokens(4096)
            .messages(messages)
            .tools(functionCallingService.getTools())  // Function Calling 활성화
            .build();
    
    log.info("Claude API 호출: sessionId={}, messageCount={}", 
            session.getId(), messages.size());
    
    MessageResponse claudeResponse = anthropicClient.sendMessage(claudeRequest);
    
    // 4️⃣ Function Calling 처리
    if (claudeResponse.getStopReason() == StopReason.TOOL_USE) {
        log.info("Tool Use 감지: sessionId={}", session.getId());
        return handleToolUse(session, claudeResponse, messages);
    }
    
    // 5️⃣ 일반 텍스트 응답 추출
    String aiContent = extractTextContent(claudeResponse);
    
    log.info("AI 응답 생성: sessionId={}, length={}", 
            session.getId(), aiContent.length());
    
    // 6️⃣ AI 응답 저장
    ChatMessage aiMessage = ChatMessage.create(
            session,
            MessageType.AI,
            aiContent
    );
    chatMessageRepository.save(aiMessage);
    
    // 7️⃣ 응답 반환
    return ChatResponse.builder()
            .sessionId(session.getId())
            .type(MessageType.AI)
            .content(aiContent)
            .sentAt(LocalDateTime.now())
            .build();
}

private String extractTextContent(MessageResponse response) {
    return response.getContent().stream()
            .filter(c -> c.getType() == ContentType.TEXT)
            .map(Content::getText)
            .collect(Collectors.joining("\n"));
}
```

**여기서 일어나는 일:**
1. DB에서 세션의 전체 대화 히스토리 조회
2. `ChatMessage` → Claude `Message` 형식으로 변환
3. **Tools 포함**하여 Claude API 호출 (Function Calling 준비)
4. `stopReason`이 `tool_use`인지 확인
   - **tool_use** → Function Calling 처리 (Step 5)
   - **일반 응답** → 바로 저장 & 반환
5. AI 응답을 `ChatMessage`로 저장 (type: AI)
6. `ChatResponse` 반환

### Step 3: Tool 실행

**코드:**
```java
private ChatResponse handleToolUse(
        ChatSession session,
        MessageResponse claudeResponse,
        List<Message> messages) {
    
    log.info("Tool Use 처리 시작: sessionId={}", session.getId());
    
    // 1️⃣ Tool Use 추출
    List<Content> toolUses = claudeResponse.getContent().stream()
            .filter(c -> c.getType() == ContentType.TOOL_USE)
            .toList();
    
    log.info("Tool Use 개수: {}", toolUses.size());
    
    // 2️⃣ 각 Tool 실행
    List<Content> toolResults = new ArrayList<>();
    
    for (Content toolUse : toolUses) {
        log.info("Tool 실행: name={}, input={}", 
                toolUse.getName(), toolUse.getInput());
        
        // FunctionCallingService에게 실행 위임
        Object result = functionCallingService.executeFunction(
                toolUse.getName(),
                toolUse.getInput()
        );
        
        log.info("Tool 실행 결과: name={}, resultType={}", 
                toolUse.getName(), result.getClass().getSimpleName());
        
        // 3️⃣ Tool Result 생성
        toolResults.add(Content.toolResult(
                toolUse.getId(),
                convertToJson(result)
        ));
    }
    
    // 4️⃣ Claude에게 Tool 결과 전달하여 자연어 응답 생성
    messages.add(Message.assistant(claudeResponse.getContent()));  // AI의 tool_use
    messages.add(Message.user(toolResults));  // Tool 실행 결과
    
    log.info("Tool 결과를 Claude에게 전달: messageCount={}", messages.size());
    
    MessageRequest followUpRequest = MessageRequest.builder()
            .model("claude-sonnet-4-20250514")
            .maxTokens(4096)
            .messages(messages)
            .tools(functionCallingService.getTools())
            .build();
    
    MessageResponse finalResponse = anthropicClient.sendMessage(followUpRequest);
    
    // 5️⃣ 최종 응답 저장 & 반환
    String aiContent = extractTextContent(finalResponse);
    
    log.info("최종 AI 응답 생성: sessionId={}, length={}", 
            session.getId(), aiContent.length());
    
    ChatMessage aiMessage = ChatMessage.create(
            session,
            MessageType.AI,
            aiContent
    );
    chatMessageRepository.save(aiMessage);
    
    return ChatResponse.from(aiMessage);
}

private String convertToJson(Object obj) {
    try {
        return objectMapper.writeValueAsString(obj);
    } catch (JsonProcessingException e) {
        throw new RuntimeException("JSON 변환 실패", e);
    }
}
```

**여기서 일어나는 일:**
1. Claude 응답에서 `tool_use` 타입의 Content 추출
2. 각 Tool을 순차적으로 실행
3. 실행 결과를 `tool_result` 형식으로 변환
4. **대화 히스토리에 추가:**
   - AI의 tool_use 메시지
   - Tool 실행 결과
5. Claude에게 다시 전송하여 자연어 응답 생성
6. 최종 응답 저장 & 반환

### Step 4: FunctionCallingService - 실제 함수 실행

**코드:**
```java
@Service
@RequiredArgsConstructor
@Slf4j
public class FunctionCallingService {
    
    private final HospitalService hospitalService;
    private final ReservationService reservationService;
    private final ObjectMapper objectMapper;
    
    /**
     * Function 실행
     */
    public Object executeFunction(String functionName, Map<String, Object> input) {
        
        log.info("Function 실행: name={}, input={}", functionName, input);
        
        return switch (functionName) {
            
            // 병원 검색
            case "search_hospitals" -> {
                String location = (String) input.get("location");
                String category = (String) input.get("category");
                
                log.info("병원 검색 시작: location={}, category={}", 
                        location, category);
                
                List<HospitalDto> hospitals = hospitalService
                        .searchHospitals(location, category);
                
                log.info("병원 검색 완료: count={}", hospitals.size());
                
                yield hospitals;
            }
            
            // 내 예약 조회
            case "get_my_reservations" -> {
                Long userId = ((Number) input.get("userId")).longValue();
                
                log.info("예약 조회 시작: userId={}", userId);
                
                List<ReservationDto> reservations = reservationService
                        .getMyReservations(userId);
                
                log.info("예약 조회 완료: count={}", reservations.size());
                
                yield reservations;
            }
            
            // 예약 가능 시간 조회
            case "get_available_slots" -> {
                Long hospitalId = ((Number) input.get("hospitalId")).longValue();
                String dateStr = (String) input.get("date");
                LocalDate date = LocalDate.parse(dateStr);
                
                log.info("예약 가능 시간 조회: hospitalId={}, date={}", 
                        hospitalId, date);
                
                List<TimeSlotDto> slots = reservationService
                        .getAvailableSlots(hospitalId, date);
                
                log.info("예약 가능 시간 조회 완료: count={}", slots.size());
                
                yield slots;
            }
            
            // 예약 생성
            case "create_reservation" -> {
                Long userId = ((Number) input.get("userId")).longValue();
                Long hospitalId = ((Number) input.get("hospitalId")).longValue();
                String dateTimeStr = (String) input.get("appointmentDateTime");
                LocalDateTime appointmentDateTime = LocalDateTime.parse(dateTimeStr);
                
                log.info("예약 생성 시작: userId={}, hospitalId={}, dateTime={}", 
                        userId, hospitalId, appointmentDateTime);
                
                ReservationDto reservation = reservationService
                        .createReservation(userId, hospitalId, appointmentDateTime);
                
                log.info("예약 생성 완료: reservationId={}", reservation.getId());
                
                yield reservation;
            }
            
            // 예약 취소
            case "cancel_reservation" -> {
                Long userId = ((Number) input.get("userId")).longValue();
                Long reservationId = ((Number) input.get("reservationId")).longValue();
                
                log.info("예약 취소 시작: userId={}, reservationId={}", 
                        userId, reservationId);
                
                reservationService.cancelReservation(userId, reservationId);
                
                log.info("예약 취소 완료: reservationId={}", reservationId);
                
                yield Map.of("success", true, "message", "예약이 취소되었습니다.");
            }
            
            default -> {
                log.error("알 수 없는 함수: {}", functionName);
                throw new IllegalArgumentException("Unknown function: " + functionName);
            }
        };
    }
```

### Step 5: HospitalService - DB 조회

**코드:**
```java
@Service
@RequiredArgsConstructor
@Slf4j
public class HospitalService {
    
    private final HospitalRepository hospitalRepository;
    
    public List<HospitalDto> searchHospitals(String location, String category) {
        
        log.info("병원 검색 쿼리 실행: location={}, category={}", 
                location, category);
        
        // DB 쿼리
        List<Hospital> hospitals;
        
        if (category != null && !category.isBlank()) {
            hospitals = hospitalRepository
                    .findByLocationContainingAndCategoryContaining(location, category);
        } else {
            hospitals = hospitalRepository
                    .findByLocationContaining(location);
        }
        
        log.info("병원 검색 결과: count={}", hospitals.size());
        
        // DTO 변환
        return hospitals.stream()
                .map(h -> HospitalDto.builder()
                        .id(h.getId())
                        .name(h.getName())
                        .address(h.getAddress())
                        .phone(h.getPhone())
```

```java
private ChatResponse switchToConsultant(ChatSession session) {

    session.waitForConsultant();

            session.getId(), "ACTIVE", "WAITING");

            MessageType.SYSTEM,

    );
```

```java
@PostMapping("/api/consultant/pick")
@ResponseBody
public SessionAssignedEvent pickNextSession(
        @AuthenticationPrincipal AuthUser authUser) {
    
    Optional<ChatSession> session = consultantService
            .pickNextWaitingSession(authUser.getUserId());
    
    if (session.isPresent()) {
        ChatSession s = session.get();
        return new SessionAssignedEvent(
                s.getId(),
                s.getUser().getId(),
                s.getUser().getUsername()
        );
    } else {
        throw new GlobalException(ConsultantErrorCode.NO_WAITING_SESSION);
    }
}

@Service
public class ConsultantService {
    
    @Transactional
    public Optional<ChatSession> pickNextWaitingSession(Long consultantId) {
        
        log.info("대기 세션 할당 요청: consultantId={}", consultantId);
        
        User consultant = userRepository.findById(consultantId)
                .orElseThrow(() -> new GlobalException(
                        UserErrorCode.USER_NOT_FOUND));
        
        // 1️⃣ 가장 오래 대기한 세션 찾기 (FIFO)
        Optional<ChatSession> sessionOpt = chatSessionRepository
                .findFirstByStatusOrderByUpdatedAtAsc(SessionStatus.WAITING);
        
        if (sessionOpt.isEmpty()) {
            log.info("대기 중인 세션 없음");
            return Optional.empty();
        }
        
        ChatSession session = sessionOpt.get();
        
        log.info("대기 세션 발견: sessionId={}, userId={}, waitTime={}초", 
                session.getId(), 
                session.getUser().getId(),
                Duration.between(session.getUpdatedAt(), LocalDateTime.now()).getSeconds());
        
        // 2️⃣ 상담원 할당
        session.assignConsultant(consultant);
        
        // 3️⃣ 세션 상태 변경: WAITING → ACTIVE
        session.activate();
        
        chatSessionRepository.save(session);
        
        // 4️⃣ 시스템 메시지 저장
        ChatMessage systemMessage = ChatMessage.create(
                session,
                MessageType.SYSTEM,
                String.format("상담원 %s님이 연결되었습니다. 무엇을 도와드릴까요?", 
                        consultant.getUsername())
        );
        chatMessageRepository.save(systemMessage);
        
        log.info("상담원 할당 완료: sessionId={}, consultantId={}, consultantName={}", 
                session.getId(), consultantId, consultant.getUsername());
        
        return Optional.of(session);
    }
}
```

## 1. 세션 관리

### ChatSession 엔티티

```java
@Entity
public class ChatSession extends BaseEntity {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @ManyToOne
    @JoinColumn(name = "user_id")
    private User user;  // 세션 소유자
    
    @ManyToOne
    @JoinColumn(name = "consultant_id")
    private User consultant;  // 할당된 상담원 (nullable)
    
    @Enumerated(EnumType.STRING)
    private SessionMode mode;  // AI, CONSULTANT
    
    @Enumerated(EnumType.STRING)
    private SessionStatus status;  // ACTIVE, WAITING, CLOSED
}
```

### 세션 모드 (SessionMode)

| 모드 | 설명 | 응답 주체 |
|------|------|----------|
| **AI** | AI 챗봇 모드 | Claude API |
| **CONSULTANT** | 상담원 모드 | 실제 상담원 |

### 세션 상태 (SessionStatus)

| 상태 | 설명 | 전환 조건 |
|------|------|----------|
| **ACTIVE** | 활성 세션 | 세션 생성 시 OR 상담원 할당 시 |
| **WAITING** | 상담원 대기 중 | 상담원 연결 요청 시 |
| **CLOSED** | 종료된 세션 | 사용자 또는 상담원이 종료 시 |

## 3. Function Calling 흐름

```
1. 사용자 메시지
   "서울에 있는 치과 찾아줘"
   ↓
2. Claude가 Tool Use 결정
   tool_use: {
     name: "search_hospitals",
     input: {location: "서울", category: "치과"}
   }
   ↓
3. FunctionCallingService.executeFunction()
   ↓
4. HospitalService.searchHospitals("서울", "치과")
   ↓
5. DB 쿼리 실행
   SELECT * FROM hospitals 
   WHERE location LIKE '%서울%' 
   AND category LIKE '%치과%'
   ↓
6. List<Hospital> → JSON 변환
   [
     {id: 1, name: "서울치과", ...},
     {id: 2, name: "강남치과", ...}
   ]
   ↓
7. Claude에게 결과 전달
   ↓
8. Claude가 자연어로 포맷팅
   "서울에 다음과 같은 치과들이 있습니다:
    1. 서울치과..."
   ↓
9. 사용자에게 응답
```

## 4. 상담원 연결 흐름

```
1. 사용자: "상담원 연결해주세요"
   ↓
2. 키워드 감지 (shouldSwitchToConsultant)
   ↓
3. 세션 모드 변경: AI → CONSULTANT
   ↓
4. 세션 상태 변경: ACTIVE → WAITING
   ↓
5. 대기열에 추가 (status=WAITING)
   ↓
6. 상담원: GET /api/consultant/queue/status
   응답: {waitingCount: 3}
   ↓
7. 상담원: POST /api/consultant/pick
   ↓
8. 가장 오래 대기한 세션 선택 (FIFO)
   ↓
9. 상담원 할당 (session.consultant = consultant)
   ↓
10. 세션 상태 변경: WAITING → ACTIVE
   ↓
11. 실시간 1:1 대화
    - 사용자: POST /api/chatbot/messages
    - 상담원: POST /api/consultant/send-message
   ↓
12. 상담원: POST /api/consultant/close-session
   ↓
13. 세션 상태 변경: ACTIVE → CLOSED
```

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) {
        http
            .csrf(csrf -> csrf.disable())
            .sessionManagement(session -> 
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
```
